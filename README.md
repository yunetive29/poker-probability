# Решение задачи о минимальном делителе для префиксов массива

## Постановка задачи

Дана функция минимального делителя `minD(x) = p`, где `p` — минимальное простое число, на которое делится `x`. По определению `minD(1) = 0`.

Также дана функция:
```
f(x, y) = minD(xy / gcd(x, y)²)
```

Для массива `a` длины `n` требуется для каждого префикса этого массива вычислить значение:
```
∑_{i < j} f(a_i, a_j)
```

## Примеры

- `minD(12) = 2` (12 делится на 2)
- `minD(35) = 5` (35 делится на 5)  
- `minD(179) = 179` (179 — простое число)
- `minD(1) = 0` (по определению)

## Алгоритм решения

### 1. Функция минимального делителя
Для числа `x` находим минимальный простой делитель, проверяя делимость на числа от 2 до `√x`.

### 2. Функция f(x, y)
Вычисляем `f(x, y) = minD(xy / gcd(x, y)²)`:
- Находим НОД чисел `x` и `y`
- Вычисляем `xy / gcd(x, y)²`
- Применяем функцию минимального делителя к результату

### 3. Оптимизированное вычисление префиксов
Вместо пересчета всех пар для каждого префикса, используем инкрементальный подход:
- При добавлении нового элемента в префикс добавляем только новые пары с этим элементом
- Время работы: O(n²), память: O(1)

## Сложность

- **Время**: O(n²) — для каждого префикса рассматриваем все пары
- **Память**: O(1) дополнительной памяти (не считая результат)
